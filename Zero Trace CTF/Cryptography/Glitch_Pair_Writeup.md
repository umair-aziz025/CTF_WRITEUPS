This scenario is vulnerable to the **Bellcore Attack (Boneh-DeMillo-Lipton Differential Fault Attack)** on RSA implementations using the Chinese Remainder Theorem (RSA-CRT).

When a transient hardware fault (such as voltage glitching, clock jitter, or laser injection) corrupts the computation modulo one of the prime factors (e.g. modulo $p$), but leaves the computation modulo the other prime factor (modulo $q$) uncorrupted, the difference between the valid signature $S_{\text{ok}}$ and the corrupted signature $S_{\text{bad}}$ becomes an exact integer multiple of $q$:
$$(S_{\text{ok}} - S_{\text{bad}}) \equiv 0 \pmod q$$
$$(S_{\text{ok}} - S_{\text{bad}}) \not\equiv 0 \pmod p$$

Computing the Greatest Common Divisor $\gcd(|S_{\text{ok}} - S_{\text{bad}}|, n)$ instantly extracts the prime factor $q$. Factoring $n = p \cdot q$ yields $\phi(n) = (p-1)(q-1)$, allowing us to compute the private decryption exponent $d \equiv e^{-1} \pmod{\phi(n)}$ and decrypt $c$.

6. Derive RSA private exponent $d = e^{-1} \pmod{\phi(n)}$.
7. Decrypt ciphertext $c$ via $m = c^d \bmod n$ and decode the UTF-8 flag string.

## 2. Mathematical background: RSA-CRT & Bellcore Fault Attacks

Standard RSA modular exponentiation $S = m^d \bmod n$ is computationally expensive for 1024-bit moduli. To accelerate signing, cryptographic hardware devices use the **Chinese Remainder Theorem (CRT)** optimization:

1. Precompute $d_p = d \bmod (p - 1)$ and $d_q = d \bmod (q - 1)$.
2. Compute half-size exponentiations:
   $$s_p = m^{d_p} \bmod p$$
   $$s_q = m^{d_q} \bmod q$$
3. Recombine $s_p$ and $s_q$ using Garner's formula:
   $$S = s_q + q \cdot \Big((s_p - s_q) \cdot q^{-1} \bmod p\Big)$$

### The Bellcore Fault Model (Boneh-DeMillo-Lipton)
If a hardware glitch induces a single bit-flip or computation error while calculating $s_p$, the device produces a faulted value $s'_p \ne s_p \pmod p$. However, if $s_q$ remains unaffected:

- Valid Signature $S_{\text{ok}}$:
  $$S_{\text{ok}} \equiv s_p \pmod p \quad \text{and} \quad S_{\text{ok}} \equiv s_q \pmod q$$

- Faulted Signature $S_{\text{bad}}$:
  $$S_{\text{bad}} \equiv s'_p \pmod p \quad \text{and} \quad S_{\text{bad}} \equiv s_q \pmod q$$

## 3. Vulnerability analysis: Differential Fault Subtraction

Subtracting the valid signature $S_{\text{ok}}$ and faulted signature $S_{\text{bad}}$:

1. Modulo $q$:
   $$S_{\text{ok}} - S_{\text{bad}} \equiv s_q - s_q \equiv 0 \pmod q$$
   Therefore, $q$ divides $(S_{\text{ok}} - S_{\text{bad}})$.

2. Modulo $p$:
   $$S_{\text{ok}} - S_{\text{bad}} \equiv s_p - s'_p \not\equiv 0 \pmod p$$
   Since $s'_p \ne s_p \pmod p$, $p$ does not divide $(S_{\text{ok}} - S_{\text{bad}})$.

3. Greatest Common Divisor:
   $$q = \gcd(|S_{\text{ok}} - S_{\text{bad}}|, n)$$

Notice that when **both** a valid signature $S_{\text{ok}}$ and a faulted signature $S_{\text{bad}}$ for the same message are available, we do not even need to compute $S_{\text{bad}}^e - m \pmod n$ or know the message padding. The direct difference $|S_{\text{ok}} - S_{\text{bad}}|$ directly leaks $q$ in $O(\log n)$ Euclidean steps.

## 7. Common Mistakes & Pitfalls

| Mistake | Consequence | Correction |
|---|---|---|
| Relying solely on message hashing assumptions | Fails if the message format/padding is unknown or customized | Use direct signature subtraction $\gcd(|S_{\text{ok}} - S_{\text{bad}}|, n)$ |
| Assuming fault corrupted both CRT branches | If both $s_p$ and $s_q$ fault simultaneously, $\gcd = 1$ | Requires single-branch CRT fault (which occurs naturally in clock/voltage glitching) |
| Omitting verification after signature computation | Device releases faulty signature $S_{\text{bad}}$ to adversary | Re-verify signature $S^e \equiv m \pmod n$ prior to outputting |

## 8. What Made the Challenge Solvable?

1. **Unprotected RSA-CRT Implementation:** The signing token computed signatures using CRT acceleration without checking signature validity ($S^e \bmod n \stackrel{?}{=} m$) before returning.
2. **Exposed Signature Pair:** Leaking both the valid signature $S_{\text{ok}}$ and the corrupted signature $S_{\text{bad}}$ for the same message allows direct subtraction $\gcd(|S_{\text{ok}} - S_{\text{bad}}|, n) = q$.
3. **Complete Private Key Exposure:** Factoring $n$ into $p$ and $q$ yields the private exponent $d$, breaking the system completely.
