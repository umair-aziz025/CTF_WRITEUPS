## 1. Result and overall approach

The recovered flag is:

```text

```

The challenge provides a list of **624 consecutive 32-bit integer outputs** generated by Python's built-in Pseudo-Random Number Generator (PRNG), the **Mersenne Twister (MT19937)**, along with an encrypted hex ciphertext `enc`.

While MT19937 exhibits excellent statistical randomness properties ($2^{19937}-1$ period), it is **not cryptographically secure**. The internal state array of MT19937 consists of exactly 624 32-bit unsigned integers. Every output produced by MT19937 is formed by passing a state element through a sequence of invertible bitwise operations known as **tempering**.

Because every step in the tempering function is invertible, observing 624 consecutive outputs allows us to **untemper** each output to reconstruct the exact 624-element internal state. Once the state is cloned, the generator's future state matrix $X_{k+624}$ becomes completely predictable. Converting the predicted 32-bit random outputs into big-endian byte blocks and XORing them against `enc` recovers the original flag string.

The investigation workflow follows a logical sequence:

1. Parse the array of 624 leaked 32-bit outputs `leaked` and ciphertext `enc` from `output.txt`.
2. Apply bitwise inverse tempering operations to reverse the four MT19937 tempering steps for each of the 624 outputs.
3. Reconstruct the 624-word internal state matrix of the PRNG.
4. Clone the PRNG state using `RandCrack` (or direct state injection into `random.setstate`).
5. Predict the next 9 32-bit integers (36 bytes) required to cover the 33-byte ciphertext.
6. Pack the predicted 32-bit words into big-endian byte order to construct the keystream.
7. XOR decrypt `enc` to reveal the flag text.

## 2. Mathematical background: Mersenne Twister MT19937 Architecture

The Mersenne Twister (MT19937) algorithm (developed by Makoto Matsumoto and Takuji Nishimura in 1997) is a linear feedback shift register (LFSR) over finite binary fields $\mathbb{F}_2$.

### Internal State & Recurrence
The internal state is represented as a vector of $N = 624$ words of $w = 32$ bits each:
$$\mathbf{S} = [x_0, x_1, x_2, \dots, x_{623}]$$

State progression occurs via the recurrence relation:
$$x_{k+N} = x_{k+M} \oplus \Big(((x_k \text{ AND } \mathbf{U}) \mid (x_{k+1} \text{ AND } \mathbf{L})) \mathbf{A}\Big)$$

where:
- $N = 624$ (state size)
- $M = 397$ (middle offset)
- $\mathbf{U} = \text{0x80000000}$ (upper bit mask)
- $\mathbf{L} = \text{0x7FFFFFFF}$ (lower bits mask)
- $\mathbf{A} = \text{0x9908B0DF}$ (matrix bitmask parameter)

### Tempering Transformation
When `getrandbits(32)` is called, state word $x_i$ is passed through a tempering matrix $T$ to produce output $y$:

1. $y_1 = x \oplus (x \gg 11)$
2. $y_2 = y_1 \oplus ((y_1 \ll 7) \text{ AND } \text{0x9D2C5680})$
3. $y_3 = y_2 \oplus ((y_2 \ll 15) \text{ AND } \text{0xEFC60000})$
4. $y_4 = y_3 \oplus (y_3 \gg 18)$

Output integer $y = y_4$.

## 3. Vulnerability analysis: Untempering and State Reconstruction

Because XOR $(\oplus)$ and bitwise shifts $(\ll, \gg)$ are linear operations over $\mathbb{F}_2$, every step of the tempering transformation is a bijection (one-to-one mapping) and can be reversed algebraically.

### 3.1 Reversing Right Shifts ($y \oplus (y \gg s)$)
To reverse $y = x \oplus (x \gg s)$:
- The top $s$ bits of $y$ are identical to the top $s$ bits of $x$ (since $x \gg s$ has zeros in the top $s$ bits).
- We iteratively XOR the known upper bits downwards:
  $$x = y \oplus (y \gg s) \oplus (y \gg 2s) \dots$$

### 3.2 Reversing Left Shifts with Masks ($y \oplus ((y \ll s) \text{ AND } \mathbf{M})$)
To reverse $y = x \oplus ((x \ll s) \text{ AND } \mathbf{M})$:
- The bottom $s$ bits of $y$ are identical to the bottom $s$ bits of $x$.
- We iteratively compute the lower bits upwards:
  $$x = y \oplus ((x \ll s) \text{ AND } \mathbf{M})$$

### 3.3 Full Untempering Function
```python
def untemper(y):
    y ^= (y >> 18)
    y ^= (y << 15) & 0xefc60000
    y ^= (y << 7) & 0x9d2c5680
    y ^= (y << 7) & 0x9d2c5680
    y ^= (y << 7) & 0x9d2c5680
    y ^= (y << 7) & 0x9d2c5680
    y ^= (y >> 11)
    y ^= (y >> 11)
    return y
```

Passing all 624 leaked outputs through `untemper()` yields the exact internal state array $[x_0, x_1, \dots, x_{623}]$.

## 7. Common Mistakes & Pitfalls

| Mistake | Consequence | Correction |
|---|---|---|
| Assuming MT19937 is cryptographically secure | Leaking 624 outputs completely compromises all future/past outputs | Use CSPRNGs (e.g. `secrets` module, `/dev/urandom`, AES-CTR DRBG) for cryptography |
| Using `random.seed(seed)` with small/predictable seeds | Vulnerable to brute-force seed search | Use high-entropy random seeds from OS entropy pool |
| Expecting non-linear state mixing | MT19937 bit transitions are linear over $\mathbb{F}_2$ | Apply non-linear cryptographic hash functions (e.g. SHA-256) over PRNG outputs |
| Byte endianness mismatch during keystream assembly | `to_bytes(4, 'little')` produces corrupted plaintext | Match generator's byte packing (big-endian 32-bit blocks) |
